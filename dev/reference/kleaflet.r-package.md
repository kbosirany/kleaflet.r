# kleaflet.r: Concise, Composable Interactive Maps from a Single Call

Draw a complete interactive 'leaflet' map (coordinates, colour palettes,
legends, popups, labels, groups, base map, view) with a single short
call, and compose maps with the '+' operator through the 'kleaflet' S3
class. Layer types, themes and palettes live in extensible registries.
